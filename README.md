# Búsqueda de casas

Sitio estático para la shortlist de casas de Toia.

- index.html: interfaz.
- styles.css: diseño responsive.
- properties.js: base verificada.
- app.js: filtros, favoritos, papelera y restauración.

Pensado para publicarse con GitHub Pages desde main.

Favoritos y Papelera se guardan en el navegador. La base de propiedades queda versionada en GitHub y puede editarse desde ChatGPT.
